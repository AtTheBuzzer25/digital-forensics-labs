## Repository guide

- `reports/PROJECT_REPORT_TEMPLATE.md`: structure for an evidence-backed report.
- `evidence/README.md`: instructions for screenshots and supporting artifacts.
- `docs/PROJECT_CHECKLIST.md`: criteria to complete before marking a project finished.

## Reporting standard

Report only actions actually performed and results actually observed. Identify academic work and simulated data explicitly. Tie conclusions to artifacts, tool output, or screenshots. Publish only material you own or have permission to share, with personal information and credentials removed.
